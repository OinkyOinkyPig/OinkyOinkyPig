## How to use
Use main.py. Edit the script between where it says, "SETTINGS" and where it says, "DO NOT EDIT BEYOND THIS POINT." Make sure to run in Google Colab. It will automatically download the data pack.

## NOTICE
After running the command, there is no way to remove it from your world. Do not apply to worlds you care about.

You may use this tool in any way you want.
